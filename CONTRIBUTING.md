# Contributing / Katkı

Read LICENSE, AGENTS.md and docs/SDK_COMPATIBILITY.md first. Use Node24.20.0,
pnpm11.22.0, exact dependency pins and the lockfile. Run `pnpm check` and
`pnpm verify:pack`. Keep examples executable with the real official MCP client.
New supported versions require an executed matrix, not a widened peer range.

Do not copy proprietary cloud code, production records or credentials into
this repository. Public wire contracts and isolated fixtures are permitted.
Tests must demonstrate privacy and behavior preservation. Unknown observations
remain unknown. Owner authorization is required before public repository or
package publication. Attribution and final npm scope remain release gates.

**TR:** Önce lisans ve repo kurallarını okuyun. Gerçek MCP testlerini,
tip kontrolünü ve bağımsız paket kurulumunu çalıştırın. Özel cloud kodu,
üretim verisi veya kimlik bilgisi eklemeyin. Destek aralığı testle kanıtlanır.
Yayım için sahibin açık yetkisi gerekir.
