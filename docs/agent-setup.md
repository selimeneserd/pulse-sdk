# AI-agent setup recipe / AI-agent kurulum tarifi

This recipe targets the exact `@reviseflow/pulse@0.2.1` and `@reviseflow/pulse-core@0.2.1` packages with installed MCP 2.0.0. Use it alongside Cloud onboarding when Cloud is explicitly selected. The 0.2.1 CLI fixes the executable-symlink and hoisted-resolution bugs in 0.2.0; see [tooling](tooling.md). It never requests secrets in chat.
